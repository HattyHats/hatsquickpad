VERSION 4.0 PRO

Quick-Pad

Zero-Knowledge Real-Time Scratchpad • v4.0 Pro

QuickPad is a hyper-fast, serverless scratchpad that syncs instantly across your devices. Engineered for pure speed and absolute privacy: no accounts, no trackers, and no server-side plaintext storage. Open the link, type, and share.

✨ Key Features & Capabilities
  • 🔒 Zero-Knowledge Architecture: AES-256 encryption keys are generated locally and stored exclusively in the URL hash (`#`). They never touch the server.
  • 🛡️ Zero-Knowledge Privacy Inspector: Live, split-screen cryptographic audit verifying real-time ciphertext, derivation salt, and zero-byte server leakage.
  • ✍️ Floating Format Mini-Bar: Highlight any text to instantly format bold, italic, headings, checklists, links, and code without remembering Markdown syntax.
  • 🍅 Pomodoro Focus Timer: Built-in 25/5 deep work cycles in the HUD with procedural synthesized acoustic chime bells.
  • 🎨 Social Note Card Exporter: Turn any note or code snippet into a beautiful, high-res social image card with custom cyberpunk gradients.
  • 🔒 Nested Secret Tabs (Vault-in-a-Vault): Lock individual tabs behind a secondary passphrase for multi-tenant privacy.
  • 🗣️ On-Device Voice Dictation: Stream speech to text locally into notes with zero third-party audio transmission.
  • 🖌️ Live Collaborative Whiteboard: Real-time 250ms vector stroke streaming across `.draw` tabs with infinite pens, highlighters, and erasers.
  • ⚡ Real-Time Live Collaboration: Peer keystrokes, remote cursor positions, collaborator avatars, and live typing indicators update with ultra-low latency.
  • 🎙️ Encrypted P2P Voice Walkie-Talkie: Push-to-talk WebRTC audio channel directly between active collaborators with audio visualizer ring.
  • 🎉 Live Cursor Emoji Flares: Send floating reaction particles (`🔥 💡 🚀 🔒 👏` or `Ctrl+1..5`) rising straight from your collaborator cursor in real time.
  • 🔊 Synthesized Mechanical Switch Audio: Pure Web Audio API procedural sound engine with Thock, Click, IBM Model M, and Cyber sound profiles.
  • ⚡ Cipher Glitch & WPM Streak: Hollywood-style matrix decryption effect on note load, plus real-time typing speed gauge with blazing cyan fire mode at 80+ WPM.
  • 🕶️ Stealth Camouflage & Duress Decoy: Instant Panic Boss Key (`Alt+P` or double-tap `Esc`) swaps to a realistic office document. Duress PIN unlocks a benign decoy vault under coercion.
  • 🖼️ Zero-Knowledge Image Paste & Drop: Paste screenshots or drag images directly into notes; automatically optimized and encrypted with AES-256.
  • 🔐 Self-Decrypting HTML Exporter: Export notes as standalone zero-dependency encrypted `.html` files that decrypt locally in any browser with your passphrase.
  • ☑️ Interactive Task Progress: Live HUD counter detects markdown `- [ ]` checkboxes and displays real-time completion percentages.
  • 🔍 Find & Replace (`⌘F` / `Ctrl+F`): Fast in-document search with match navigation and single/bulk replace.
  • ⌨️ Command Palette (`⌘K` / `Ctrl+K`): Instant access to all actions, commands, and tab switching via keyboard.
  • 📁 Import & Export: Export your notes as `.md`, `.txt`, `.html`, or `.json` workspace backups.
  • 💬 Secure Peer DMs: RSA-OAEP 2048-bit encrypted direct messaging. Click any collaborator in the presence bar to chat privately.
  • 🔥 Self-Destruct & Burn Notes: Set timed auto-destruct workspaces or one-time burn links that wipe from the database the moment they are opened.
🛡️ Cryptographic Security Architecture

All workspace content is encrypted locally using AES-256 (CBC) prior to transport. The database only acts as an encrypted relay and stores ciphertext. Direct messages utilize RSA-OAEP 2048-bit with SHA-256 with hybrid AES session keys generated on device. No unencrypted content ever touches the wire.

1
Key Generation on Device: Your unique AES-256 decryption key is generated locally and stored exclusively in the URL hash (after #). Under internet standard RFC 3986 §3.5, web browsers physically refuse to transmit hash fragments to any web server or network relay.
